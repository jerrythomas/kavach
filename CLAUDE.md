# Kavach — Agent Instructions

This repo's canonical agent instructions live in **`AGENTS.md`** — read it
before doing any work. It covers the mandatory sensei-first load (workflow
state, layered context, rules), the Feature → Plan → Implement pipeline,
commands, lint rules, and git branching.

MCP (tools named `sensei_*`) — there is no `agents/` directory.
