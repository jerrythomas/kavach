# `@kavach/vite` Ambient `.d.ts` Generation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `@kavach/vite` generate an ambient `src/kavach.d.ts` typing its four virtual modules (`$kavach/auth`, `$kavach/config`, `$kavach/routes`, `$kavach/providers`) so SvelteKit consumers delete their hand-written shim and change nothing in `tsconfig`.

**Architecture:** A pure `generateDeclarations()` string-builder in `packages/vite/src/generate.js` produces the declaration text (colocated with the JS generators, so it stays in lockstep). A `writeDeclarationFile()` helper in `packages/vite/src/index.js` writes it only when content differs. The plugin loads config during `configResolved` (so a cold `svelte-kit sync && svelte-check` sees the file) and again in `buildStart` (dev/build), emitting the declarations after config is available. A new `dts?: string | false` option (default `'src/kavach.d.ts'`) controls the path or disables the feature.

**Tech Stack:** JavaScript (ESM), Vite plugin API, Vitest, Node `fs`/`path`, SvelteKit `svelte-check`.

**Spec:** `docs/superpowers/specs/2026-07-14-vite-ambient-dts-design.md`

```js
/**
 * Write declaration content to `filePath`, but only when it differs from what is
 * already on disk. Creates parent directories as needed. Returns true if written.
 */
export function writeDeclarationFile(filePath, content) {
  if (existsSync(filePath) && readFileSync(filePath, 'utf-8') === content) {
    return false
  }
  mkdirSync(dirname(filePath), { recursive: true })
  writeFileSync(filePath, content)
  return true
}
```

describe('plugin declaration emission', () => {
  afterEach(() => vi.restoreAllMocks())

  function scratchProject() {
    const dir = mkdtempSync(join(tmpdir(), 'kavach-vite-proj-'))
    const cfg = join(dir, 'kavach.config.mjs')
    writeFileSync(cfg, "export default { adapter: 'supabase' }\n")
    return { dir, cfg }
  }

  it('writes src/kavach.d.ts during configResolved when config loads', async () => {
    const { dir, cfg } = scratchProject()
    const plugin = kavach({ configPath: cfg })
    await plugin.configResolved({ root: dir })
    const out = join(dir, 'src', 'kavach.d.ts')
    expect(existsSync(out)).toBe(true)
    expect(readFileSync(out, 'utf-8')).toContain("declare module '$kavach/auth'")
  })

  it('does not write when dts is false', async () => {
    const { dir, cfg } = scratchProject()
    const plugin = kavach({ configPath: cfg, dts: false })
    await plugin.configResolved({ root: dir })
    expect(existsSync(join(dir, 'src', 'kavach.d.ts'))).toBe(false)
  })

  it('honors a custom dts path', async () => {
    const { dir, cfg } = scratchProject()
    const plugin = kavach({ configPath: cfg, dts: 'types/kavach.d.ts' })
    await plugin.configResolved({ root: dir })
    expect(existsSync(join(dir, 'types', 'kavach.d.ts'))).toBe(true)

Add two private helpers inside `kavach()` (above the `return { ... }`):

```js
async function loadConfig() {
  if (config) return config
  const target = configPath ?? options.configPath
  if (!target) return null
  try {
    const mod = await import(target)
    config = parseConfig(mod.default)
  } catch {
    config = null
  }
  return config
}

function emitDeclarations() {
  if (dtsOption === false || !config || !viteRoot) return
  try {
    writeDeclarationFile(resolve(viteRoot, dtsOption), generateDeclarations())
  } catch {
    // best-effort: type generation must never break the build
  }
}
```

			viteMode = viteConfig.mode ?? 'development'
			await loadConfig()
			emitDeclarations()

```markdown
## Generated TypeScript declarations

The plugin writes an ambient declaration file typing its virtual modules
(`$kavach/auth`, `$kavach/config`, `$kavach/routes`, `$kavach/providers`) so
`svelte-check`/`tsc` resolve them without a hand-written shim.

- **Default location:** `src/kavach.d.ts` (SvelteKit's generated `tsconfig`
  already includes `src/**/*.ts`, so no `tsconfig` change is needed).
- **Option `dts`:** set a different path (`kavach({ dts: 'types/kavach.d.ts' })`)
  or disable generation entirely (`kavach({ dts: false })`).

The file is regenerated on dev start and build, and only rewritten when its
content changes.

### Migrating from a hand-written shim

1. Upgrade `@kavach/vite`.
2. Delete your hand-written `src/kavach.d.ts`.
3. Add `src/kavach.d.ts` to `.gitignore`.
4. Run `vite build` or start the dev server once (or `svelte-kit sync`, if your
   toolchain triggers the plugin during sync); the file regenerates.
```
